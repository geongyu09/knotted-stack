# 기능 추가

1. 사용자가 기능으로 얻으려는 결과와 완료를 확인할 방법(명령, 화면, 테스트)을 적습니다.
2. 변경이 영향을 주는 호출자, 테스트, 설정, export를 찾아서 목록으로 적습니다.
3. 코드베이스에 이미 있는 헬퍼, 컴포넌트, 패턴을 먼저 찾고, 있으면 주변 코드와 같은 방식으로 사용합니다. (`ponytail.md`)
4. 함수 경계를 넘는 변경이면 타입과 시그니처부터 적어서 사용자에게 보여 줍니다.
5. 검증할 수 있는 작은 단위로 나누어 구현하고, 단위마다 확인한 뒤 다음 단위를 시작합니다. 서로 독립인 단위는 `delegate` 스킬로 맡길 수 있습니다.
6. 1번에서 적은 방법으로 실제 결과물을 확인합니다. (`principles/prove-it-works.md`)
7. 요청하지 않은 옵션, 설정, 추상화를 넣었는지 diff를 다시 읽고 걷어냅니다.
