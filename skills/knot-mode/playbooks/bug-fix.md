# 버그 수정

배포되는 모든 줄은 실행해서 얻은 증거에 근거해야 하며, "도움이 될지도 모르는" 방어 코드는 넣지 않습니다.

1. 직접 재현합니다. 재현되지 않으면 조건을 좁히거나 로그를 심어서 재현될 때까지 시도하고, 재현 명령과 실패 출력을 기록합니다.
2. 원인 후보를 적고, 남은 범위를 가장 크게 줄이는 확인부터 실행해서 후보를 하나씩 지웁니다. 추측하지 않고 실행 결과로 지웁니다. (`principles/fix-root-causes.md`)
3. 살아남은 원인을 실행 증거로 확인한 뒤 수정을 계획합니다. 수정이 함수 경계를 넘으면 타입과 시그니처부터 적습니다.
4. 가장 작은 수정을 넣습니다. 조사와 수정이 서로 독립이면 `delegate` 스킬로 맡길 수 있습니다.
5. 1번의 재현 명령을 다시 실행해서 통과를 확인합니다. 값싼 로컬 테스트를 쓸 수 있으면 회귀 테스트를 추가합니다. (`principles/prove-it-works.md`)
6. 재현 명령, 수정 전 실패 출력, 수정 후 통과 출력을 보고합니다.

원인이 이미 증명되었고 수정이 한 함수 안에서 인터페이스를 바꾸지 않으면 2번과 3번을 `skip: 원인 증명됨`으로 건너뜁니다.
