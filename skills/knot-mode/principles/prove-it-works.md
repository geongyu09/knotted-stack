# 실제로 되는지 증명하기

"컴파일된다", "테스트를 썼다"는 완료의 증거가 아니며, 사용자가 쓰는 실제 결과물에서 확인한 결과만 증거로 인정합니다.

- CLI는 명령을 실행하고, 서버는 요청을 보내고, UI는 화면을 띄워서 확인합니다.
- 버그 수정은 수정 전에 실패하던 재현 명령이 수정 후에 통과하는지 확인합니다.
- 확인하지 못한 부분은 "확인하지 못함"이라고 보고에 적고, 통과했다고 쓰지 않습니다.
- 에이전트가 돌려준 `PASS`는 증거가 함께 있을 때만 받아들이고, 위험한 변경은 부모가 한 번 더 실행해서 확인합니다.
- 숫자를 보고할 때는 측정 방법(표본 수, 한 표본의 범위, 순서)을 함께 적습니다.
